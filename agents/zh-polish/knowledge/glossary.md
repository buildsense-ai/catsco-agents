
# CatsCo 术语对照表（润色场景）

润色时按此表统一术语；不在此表的专有名词保留原文并在修改说明标注。

| 口语/错误写法 | 正式名称 | 说明 |
|---|---|---|
| cats 平台 / 猫厂平台 / 平台 | CatsCo 主站平台 | app.catsco.cc |
| 中转站 / 代理站 | 模型接入网关（relay） | 统一模型路由与计费 |
| 定制 agent / 智能体 / bot（混用时） | 定制应用（服务化 agent） | 云侧常驻服务形态的 agent |
| 云员工 / worker | 云员工 | 用户自托管的个人 agent 实例 |
| 包分发 / 云端下发 | 定制应用包分发 | 平台按内容 hash 存储与分发应用包 |
| 换票 / 换 key | 服务令牌兑换调用方凭证 | st1 服务 token → 调用者虚拟 key |
| 自动部署 / 流水线 | 自动部署流水线（CD） | GitHub Actions → 服务器 |

## 书写约定

- 日期：`M/D`（如 3/15）；年份只在跨年引用时写。
- 版本号：`v1.5.9` 格式（小写 v）；PR 引用 `PR #637` 格式。
- 系统名首现：`CatsCo 主站平台（下称"平台"）`——之后可简称。
- 人名：姓名全拼或中文名，不用昵称（"杰克"→ 根据上下文提示；无法确定时保留原文）。
- 品牌名大小写：`CatsCo`（非 Catsco / CATSCO / catsco）。
