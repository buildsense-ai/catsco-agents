
# CatsCo 团队术语与约定（会议纪要场景）

整理纪要时按此表替换口语代号；人名、日期、系统名遵循下方约定。

| 口语代号 / 简称 | 正式名称 | 说明 |
|---|---|---|
| cats 平台 / 平台 | CatsCo 主站平台 | app.catsco.cc，用户/消息/机器人核心服务 |
| relay | 模型接入网关（relay） | 统一模型路由与计费 |
| 定制 agent / 应用 | 定制应用（服务化 agent） | 云侧常驻服务形态的 agent |
| 实例池 / 实例 | 定制应用运行实例 | 华南2 内网自托管执行节点 |
| 包分发 / 云端包分发 | 定制应用包分发 | 平台按内容 hash 存储应用包；实例自动拉取生效 |
| 换票 | 服务令牌兑换调用方凭证 | st1 服务 token → 调用者虚拟 key |
| CD | 自动部署流水线 | GitHub Actions → 服务器 |
| worker | 云员工 | 用户自托管的个人 agent 实例 |
| 周报助手 | 周报助手应用 | 把日常记录整理成周报的定制应用 |
| 会议纪要助手 | 会议纪要助手应用 | 本应用自身 |

## 团队约定

- 日期一律用 `M/D` 格式；相对时间（"下周"）保留原文并尽量补日期。
- 人名用姓名全拼或中文名，不用昵称。
- 对外系统用正式名称；内部技术讨论可保留代号。
- 决议中引用版本号/编号（如 PR #637、v1.5.9）原样保留，不改写为"最新版本"。
